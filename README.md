# Homebrew tap for monthlet

```sh
brew install --cask t27d/tap/monthlet
```

monthlet is a notes app for macOS (Apple silicon, macOS 13 or later). Notes are saved as files in a folder on your Mac.
The app updates itself, so you don't need `brew upgrade` for new versions.

`brew uninstall --zap --cask monthlet` also removes the app's settings and data under `~/Library`.
It does not remove your notes folder.

- Website: https://monthlet.ai/
- Releases: https://github.com/t27d/monthlet-releases/releases
